# Options Lot Calculator — Android + Web

An options-trading calculation toolkit for position sizing, stop-loss risk, estimated charges, trade P&L and trading calculations.

## Web app

**Windows:** double-click `run-local.bat`, then open `http://localhost:8000`.

**Linux/macOS:** run `./run-local.sh`, then open `http://localhost:8000`.

Python 3 is required for the local static server.

## Android app (Capacitor 8)

The Android app wraps the existing HTML/CSS/JavaScript calculator in a native Capacitor shell. The calculator's existing calculation engine and browser functionality are retained. The app uses a single dark Trading Green theme and a rupee-and-coins launcher icon.

Requirements: Node.js 22+, Android Studio 2025.2.1+ and an Android SDK (API 24+). Android Studio includes the supported JDK. See [docs/ANDROID.md](docs/ANDROID.md) for complete instructions.

First-time setup:

```bash
npm install
npm run build:mobile
npm run android:add
npx cap sync android
npx cap open android
```

Build a local debug APK after the Android project has been added:

```bash
npm run android:build
```

APK output: `android/app/build/outputs/apk/debug/app-debug.apk`.

A GitHub Actions workflow at `.github/workflows/android-apk.yml` builds a debug APK and publishes it as a downloadable workflow artifact. Start it from the repository's **Actions** tab.

- App name: **Options Lot Calculator**
- Application ID: `com.sunnysaxena.optionslotcalculator`
- Web assets: `www/` (generated by `npm run build:mobile`)

## Run tests

Install Node.js, then run:

```bash
npm test
```

## Project layout

- `index.html` — app markup
- `css/styles.css` — original styles
- `css/android.css` — dark, mobile-first Android presentation and safe-area layout
- `assets/app-icon.svg` — rupee, coin-stack and growth-arrow brand icon
- `scripts/apply-android-icon.mjs` — creates adaptive and density-specific Android launcher icons
- `js/app.js` — compatibility loader
- `js/legacy/app.js` — existing working UI behavior
- `js/core/` — reusable DOM, formatting and presets
- `js/features/` — feature modules and calculation functions
- `scripts/prepare-capacitor.mjs` — copies app assets into Capacitor's `www/`
- `capacitor.config.ts` — native app identity and web directory
- `docs/ANDROID.md` — Android setup and build guide
- `tests/` — automated calculation tests

## Trading and data disclaimer

No live market data, broker connection, login, or automatic order placement is added. Index lot sizes are editable presets, not live exchange data. Brokerage and other charges are simplified estimates. Verify current contract specifications and actual broker charges before trading. Option buyers can lose the entire premium paid.
