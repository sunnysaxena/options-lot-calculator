# Android app (Capacitor)

The Android app reuses the existing HTML/CSS/JavaScript calculator and keeps its existing calculation implementation as the source of truth. It ships with a single dark Trading Green theme and a rupee-and-coins launcher icon.

## Requirements

- Node.js 22 or newer
- Android Studio (current stable)
- Android SDK and platform tools
- A JDK supported by the Android Gradle Plugin installed by Capacitor

## First-time setup

```bash
npm install
npm run build:mobile
npx cap add android
npx cap sync android
npx cap open android
```

In Android Studio, allow Gradle sync to finish, select a device or emulator, then run the app.

## Build a debug APK locally

```bash
npm install
npm run android:add   # only once per checkout
npm run android:build
```

The build script generates adaptive launcher icons and legacy density icons from `assets/app-icon.svg` before compiling.

The debug APK is written to:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

For a release APK or Play Store AAB, configure signing in Android Studio/Gradle and keep signing credentials out of Git.

## Automated APK build

The workflow at `.github/workflows/android-apk.yml` runs the existing tests, generates the native Android project, builds a debug APK and uploads it as a workflow artifact. Run it from the Actions tab using **Build Android APK → Run workflow**, or push a change to a watched path.

## Project identity

- Display name: Options Lot Calculator
- Application ID: `com.sunnysaxena.optionslotcalculator`
- Capacitor web asset directory: `www/` (generated by `npm run build:mobile`)

## Important

- Lot sizes remain editable presets and are not live exchange data.
- No broker login, live market feed, order placement or financial advice is added.
- Verify current exchange contract specifications and actual broker charges before trading.
